# Restricciones

| ID | Restricción | Descripción |
|---|---|---|
| RC01 | Aplicación web | El sistema será accesible mediante un navegador web. |
| RC02 | Control de versiones | El código y documentación serán gestionados mediante Git y GitHub. |
| RC03 | API REST | La comunicación principal entre frontend y backend utilizará una API REST. |
| RC04 | Base de datos relacional | La información persistente será almacenada utilizando PostgreSQL. |
| RC05 | Backend | El backend principal será desarrollado utilizando Node.js con NestJS. |
| RC06 | Servicio inteligente | El componente encargado de la evaluación inteligente podrá desarrollarse mediante Python y FastAPI. |
| RC07 | Contenedores | Los principales componentes deberán poder desplegarse utilizando Docker. |
| RC08 | Privacidad | El acceso a información académica y de riesgo estará limitado de acuerdo con los roles autorizados. |
| RC09 | Decisión humana | Las evaluaciones generadas por el sistema serán utilizadas como apoyo y no producirán automáticamente sanciones o decisiones académicas sobre el estudiante. |
| RC10 | Costo | La arquitectura deberá priorizar tecnologías de código abierto y soluciones de bajo costo. |
