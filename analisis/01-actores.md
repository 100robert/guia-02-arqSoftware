# Actores del sistema

| Actor | ¿Qué necesita realizar? |
|---|---|
| Estudiante | Consultar información relacionada con su progreso académico y las acciones de acompañamiento registradas. |
| Tutor | Consultar estudiantes asignados, revisar alertas de riesgo, analizar indicadores, registrar intervenciones y realizar seguimiento. |
| Responsable de Bienestar Universitario | Consultar casos que requieren apoyo especializado, registrar acciones de acompañamiento y realizar seguimiento. |
| Coordinador Académico | Consultar indicadores globales, niveles de riesgo, reportes y evolución de los estudiantes. |
| Administrador | Gestionar usuarios, roles, permisos, parámetros y configuración general del sistema. |
| Sistema Académico | Proporcionar información académica como calificaciones, cursos, créditos, matrícula y otros datos necesarios para el análisis. |
| Servicio de Notificaciones | Enviar alertas y avisos generados por el sistema. |
