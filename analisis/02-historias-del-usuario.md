# Historias de usuario

| ID | Historia de usuario |
|---|---|
| HU01 | Como tutor, quiero consultar los estudiantes asignados, para conocer su situación académica. |
| HU02 | Como tutor, quiero visualizar las alertas de riesgo de mis estudiantes, para identificar oportunamente los casos que requieren revisión. |
| HU03 | Como tutor, quiero consultar los indicadores asociados al riesgo de un estudiante, para comprender los factores que originaron la alerta. |
| HU04 | Como tutor, quiero registrar una intervención realizada, para mantener evidencia del seguimiento efectuado. |
| HU05 | Como tutor, quiero consultar el historial de intervenciones de un estudiante, para conocer las acciones realizadas previamente. |
| HU06 | Como responsable de Bienestar Universitario, quiero consultar los casos derivados, para brindar acompañamiento especializado. |
| HU07 | Como coordinador académico, quiero consultar indicadores generales de riesgo, para conocer la situación de los estudiantes de la institución. |
| HU08 | Como coordinador académico, quiero consultar reportes por facultad, escuela o período académico, para analizar tendencias de riesgo. |
| HU09 | Como estudiante, quiero consultar información sobre mi progreso académico, para conocer mi evolución durante el período académico. |
| HU10 | Como administrador, quiero gestionar usuarios y roles, para controlar el acceso a las funcionalidades del sistema. |
| HU11 | Como administrador, quiero importar información académica, para mantener actualizados los datos utilizados en las evaluaciones de riesgo. |
| HU12 | Como tutor, quiero solicitar una nueva evaluación del riesgo de un estudiante, para conocer su situación actual después de una intervención. |
