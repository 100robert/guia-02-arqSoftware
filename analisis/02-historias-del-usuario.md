# Historias de Usuario

## Mentelyx

### Estudiante

| ID | Historia de usuario |
|---|---|

| HU02 | Como estudiante, quiero seleccionar mi nivel educativo, para recibir contenidos apropiados a mi etapa de aprendizaje. |
| HU03 | Como estudiante, quiero realizar una evaluación diagnóstica, para conocer mi nivel inicial de conocimientos. |
| HU04 | Como estudiante, quiero recibir una ruta de aprendizaje personalizada, para estudiar de acuerdo con mis conocimientos y dificultades. |

| HU07 | Como estudiante, quiero recibir actividades de refuerzo cuando presente dificultades, para mejorar los conocimientos que todavía no domino. |
| HU08 | Como estudiante, quiero reforzar conocimientos prerrequisitos cuando sean necesarios, para comprender adecuadamente temas posteriores. |
| HU09 | Como estudiante, quiero recibir retroalimentación después de responder un ejercicio, para comprender mis errores. |
| HU10 | Como estudiante, quiero solicitar pistas durante determinados ejercicios, para recibir orientación sin obtener directamente la respuesta. |
| HU11 | Como estudiante, quiero buscar y consultar contenidos educativos, para complementar mi aprendizaje. |
| HU12 | Como estudiante, quiero consultar mi nivel de dominio por área, tema y habilidad, para conocer mi progreso. |

| HU14 | Como estudiante, quiero participar en evaluaciones y simulacros, para comprobar mi nivel de preparación. |
| HU15 | Como estudiante, quiero consultar los planes disponibles, para seleccionar el acceso que mejor se adapte a mis necesidades. |
| HU16 | Como estudiante, quiero contratar un plan de suscripción, para acceder a funcionalidades adicionales de Mentelyx. |
| HU17 | Como estudiante de una institución aliada, quiero verificar mi condición de beneficiario, para acceder a las ventajas establecidas por su convenio con Mentelyx. |
| HU18 | Como estudiante beneficiario de un convenio, quiero obtener el descuento correspondiente al contratar un plan, para acceder a funcionalidades avanzadas a un costo reducido. |
