# Requisitos funcionales

| ID | Requisito funcional |
|---|---|
| RF01 | El sistema debe permitir autenticar a los usuarios mediante credenciales. |
| RF02 | El sistema debe permitir gestionar usuarios, roles y permisos. |
| RF03 | El sistema debe permitir registrar e importar información académica de los estudiantes. |
| RF04 | El sistema debe permitir consultar la información académica de un estudiante. |
| RF05 | El sistema debe permitir ejecutar la evaluación de riesgo de deserción de un estudiante. |
| RF06 | El sistema debe permitir clasificar el nivel de riesgo identificado. |
| RF07 | El sistema debe permitir consultar los indicadores asociados a una evaluación de riesgo. |
| RF08 | El sistema debe generar alertas cuando un estudiante alcance un nivel de riesgo que requiera seguimiento. |
| RF09 | El sistema debe permitir a los tutores consultar las alertas correspondientes a sus estudiantes. |
| RF10 | El sistema debe permitir registrar intervenciones realizadas sobre un estudiante. |
| RF11 | El sistema debe permitir consultar el historial de intervenciones y seguimiento. |
| RF12 | El sistema debe permitir derivar determinados casos a Bienestar Universitario. |
| RF13 | El sistema debe permitir reevaluar periódicamente el riesgo del estudiante. |
| RF14 | El sistema debe permitir visualizar indicadores generales mediante un dashboard. |
| RF15 | El sistema debe permitir generar reportes por período académico, facultad, escuela y nivel de riesgo. |
| RF16 | El sistema debe enviar notificaciones relacionadas con nuevas alertas y acciones de seguimiento. |
| RF17 | El sistema debe registrar las operaciones relevantes realizadas por los usuarios para fines de auditoría. |
