# Requisitos Funcionales

## Mentelyx

| ID | Requisito funcional |
|---|---|

| RF01 | El sistema debe permitir autenticar estudiantes, docentes y responsables de instituciones educativas. |
| RF02 | El sistema debe permitir al estudiante realizar evaluaciones diagnósticas. |
| RF03 | El sistema debe registrar las respuestas proporcionadas durante una evaluación. |
| RF04 | El sistema debe determinar el nivel inicial de conocimiento del estudiante por tema y habilidad. |
| RF05 | El sistema debe mantener un perfil individual de aprendizaje para cada estudiante. |
| RF06 | El sistema debe registrar las interacciones realizadas durante las actividades de aprendizaje. |
| RF07 | El sistema debe registrar respuestas correctas e incorrectas, cantidad de intentos y utilización de pistas. |
| RF08 | El sistema debe analizar el desempeño del estudiante utilizando la información generada durante su proceso de aprendizaje. |
| RF09 | El sistema debe estimar el nivel de dominio del estudiante para cada habilidad. |
| RF10 | El sistema debe actualizar el perfil de aprendizaje conforme el estudiante realice nuevas actividades. |
| RF11 | El sistema debe generar una ruta de aprendizaje personalizada a partir del perfil del estudiante. |
| RF12 | El sistema debe seleccionar actividades de acuerdo con el nivel de dominio del estudiante. |
| RF13 | El sistema debe seleccionar ejercicios considerando la habilidad y el nivel de dificultad apropiado. |
| RF14 | El sistema debe proporcionar contenidos relacionados con las habilidades que el estudiante necesita aprender o reforzar. |
| RF15 | El sistema debe proporcionar retroalimentación después de las actividades realizadas. |
| RF16 | El sistema debe permitir al estudiante solicitar pistas durante determinados ejercicios. |
| RF17 | El sistema debe detectar habilidades en las que el estudiante presenta dificultades. |
| RF18 | El sistema debe recomendar actividades de refuerzo cuando se identifiquen dificultades persistentes. |
| RF19 | El sistema debe identificar conocimientos prerrequisitos relacionados con una dificultad detectada. |
| RF20 | El sistema debe permitir reforzar conocimientos prerrequisitos antes de continuar con conocimientos que dependen de ellos. |
| RF21 | El sistema debe determinar cuándo el estudiante alcanza el nivel de dominio necesario para avanzar. |
| RF22 | El sistema debe registrar el historial de progreso del estudiante. |
| RF23 | El sistema debe permitir al estudiante consultar su progreso por curso, tema y habilidad. |
| RF24 | El sistema debe permitir al docente consultar el progreso de los estudiantes pertenecientes a sus grupos. |
| RF25 | El sistema debe identificar las habilidades que presentan mayores dificultades dentro de un grupo. |
| RF26 | El sistema debe generar indicadores agregados sobre el progreso de un grupo. |
| RF27 | El sistema debe permitir al docente crear y gestionar grupos de aprendizaje. |
| RF28 | El sistema debe generar un código de acceso único para cada grupo. |
| RF29 | El sistema debe permitir al estudiante incorporarse a un grupo mediante un código de acceso válido. |
| RF30 | El sistema debe mantener la relación entre institución educativa, docentes, grupos y estudiantes. |
| RF31 | El sistema debe permitir al docente asignar cursos o actividades disponibles a un grupo. |
| RF32 | El sistema debe permitir al responsable de una institución educativa gestionar los docentes vinculados a su institución. |
| RF33 | El sistema debe permitir al responsable institucional consultar los grupos registrados en su institución. |
| RF34 | El sistema debe impedir que un docente consulte información individual de estudiantes que no pertenezcan a sus grupos. |
| RF35 | El sistema debe permitir generar notificaciones relacionadas con actividades o progreso cuando corresponda. |
